## Resumo dos Conceitos Praticados

Durante as atividades no Coddy pratiquei conceitos básicos de banco de dados e SQL.

Aprendi sobre tabelas, colunas, registros, uso de `SELECT`, `WHERE`, `DISTINCT` e condições de comparação. Também pratiquei filtros em consultas SQL e a seleção de dados específicos em uma tabela.

A principal dificuldade foi compreender alguns enunciados em inglês, mas ao longo das atividades consegui entender melhor a estrutura das consultas e a lógica dos comandos SQL.
